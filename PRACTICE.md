# Practice Validation — C6 Labelling (checkpoint 1.1)

This branch is your **practice run for the real C06 validation**, which uses exactly
this format. Every comment has been stripped from the scripts — including all your
labels. Your job is to put the labels back, from understanding.

## The task — 30 minutes

Add `# C6xx` skill-code labels to the code on this branch:

- **Each code at most once** — place it on the instance that best demonstrates it.
- **Codes from the 7–8 and 9–10 bands need a one-sentence why** in the comment,
  not just the code number.
- **The count is a ceiling, not a target.** 20 well-chosen labels with good whys
  beat 34 rushed ones. Not every code has an honest site in this project — placing
  a code that isn't really there costs more than leaving it out.

## Rules

- **AI off. Feedback tabs closed.** (Your teacher will say whether the skill-code
  reference card is allowed on the desk.)
- Work only on this branch. If you have uncommitted work on `main`, commit it there
  first, then `git switch checkpoint1.1`.
- When told: commit your labels on this branch and push. Your commit is the record.

## What this is for

- It does **not** change your checkpoint score. It is practice for the format,
  and it tells us both what stuck.
- The debrief straight after is the real learning: you'll talk through *why* you
  placed what you placed.
